## Омар — тестирование

Играй на `https://beibitai.github.io/nasa2026-mission-trainer/play/`.

Что проверить:
1. **Обычная партия** без станции. Буря должна прийти внезапно, а в разборе сола появиться «Surprise!».
2. **Партия со станцией** (📡 на 1-м соле). За сол до бури приходит предупреждение.
3. **Проигрыши:**
   - не давать энергию Life Support → воздух кончается;
   - не давать энергию Greenhouse → кончается еда;
   - вкладывать всё в науку без щита во время бури → доза.
4. **Телефон.** Всё помещается, кнопки нажимаются.
5. **Режимы ссылки.**
   - `?offline` — командир на встроенных текстах, игра работает.
   - `?seed=7` — партия повторяется.

**Шаблон бага в чат:** `что делал → что ожидал → что случилось · браузер/телефон · сол · скриншот`.

## Бексултан — 3D для веба

Делаем 3D-вид, только если **Habitat в `.glb` будет к 16:00**, иначе остаются рендеры для видео.

Экспорт из Blender: **File → Export → glTF 2.0**, формат **glTF Binary (.glb)**.
- Включить: Apply Modifiers, +Y Up.
- Масштаб: 1 unit = 1 м.
- Материалы: Principled BSDF, текстуры ≤ 1024².

Бюджет на модуль: ≤ 8k треугольников.

Порядок моделей:
1. `habitat.glb`
2. `greenhouse.glb`
3. `solar_panel.glb`
4. `weather_station.glb`
5. `astronaut.glb`

Файлы класть в `web/play/models/` (без Git LFS — Pages не отдаёт LFS-файлы). `.blend` хранить в `art-source/blender/`.

**Рендеры** (PNG 1920×1080) положить в `docs/media/` к 18:00, для видео и слайдов.
