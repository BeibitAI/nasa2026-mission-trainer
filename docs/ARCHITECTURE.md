# Architecture

## 1. Overview

```
 Browser
 ├─ Landing (GitHub Pages, web/)  ──iframe──►  Unity WebGL (web/play/)
 │                                             bundled: RAD data, configs,
 │                                             fallback texts, DONKI snapshot
 └──────────────────────────────────────────────┬─────────────
                                                │ HTTPS JSON, 6 s timeout
                                   ┌────────────▼────────────┐
                                   │ FastAPI backend (Render) │
                                   │ /api/commander           │──► Gemini API (key in env)
                                   │ /api/spaceweather        │──► NASA DONKI (6 h cache)
                                   │ /api/scores              │──► Supabase Postgres
                                   └──────────────────────────┘
```

**Rule #1: the game is fully playable without the backend.** Render asleep, Gemini quota gone, network blocked → bundled data + fallback texts. Judges may open the link weeks later.

- Game + landing: **GitHub Pages** (`https://beibitai.github.io/nasa2026-mission-trainer/`), deployed by GitHub Actions from `web/`.
- Mirror: **itch.io** (Arystan, `butler`).
- Backend: **Render** free web service (sleeps after ~15 min idle → UptimeRobot pings `/health` every 5 min).
- Leaderboard DB: **Supabase** free Postgres (Render free disk is wiped on deploy).

Bexultan's FBX lives as the `Model` child inside Arystan's prefabs — re-exporting the FBX updates the prefab with no prefab edit.

### Git
- Force Text serialization, Visible Meta Files, always commit `.meta`.
- LFS **only** under `unity/**` and `art-source/**` (see `.gitattributes`). `web/` must not use LFS — GitHub Pages serves LFS pointers, not files.
- `.blend` never in `Assets/` (Unity would need Blender installed on every machine).

```json
  "units": "uGy/h (absorbed dose rate)",

      "peakValue": 23.18 }

```

`scenario_mars.json` — balance (copy for Moon):
```json
{
  "id": "mars", "sols": 14, "powerPerSol": 10, "crew": 4,
  "systems": {
    "lifeSupport": { "upkeep": 3, "gainPerExtraUnit": 6, "lossPerMissingUnit": 12 },
    "greenhouse":  { "upkeep": 2, "gainPerExtraUnit": 5, "lossPerMissingUnit": 8 },
    "shield":      { "maxReduction": 0.7, "reductionPerUnit": 0.15 },
    "science":     { "pointsPerUnit": 1, "goal": 12 }
  },

```

Also: `events.json` (id, probability, effects, source ref), `commander_fallback.json` (templates like `"Your shield blocked {pct}% of the storm!"`), `facts.json` (OSDR cards), `sources.json` (in-game Data Sources screen — same file copied to `web/data/` for the landing), `config.json` (`apiBaseUrl`).

`JsonUtility` caveats: no dictionaries, no top-level arrays → wrap arrays in an object.

### Backend API

**`POST /api/commander`** — briefing/debrief text
```json
// request
{ "sessionId": "uuid", "scenario": "mars", "sol": 5, "phase": "debrief",
  "allocation": { "lifeSupport": 3, "greenhouse": 2, "shield": 4, "science": 1 },
  "before": { "air": 72, "food": 60, "dose": 18, "science": 5 },
  "after":  { "air": 65, "food": 55, "dose": 22, "science": 6 },
  "events": [ { "id": "sep_2017", "fact": "Curiosity measured 2.3x normal radiation on 11 Sep 2017" } ],
  "outcome": "warning" }
// response — always 200
{ "text": "Great call on the shield! ...", "tip": "Food is getting low — feed the greenhouse tomorrow?", "source": "gemini" }
```
`source` ∈ `gemini | cache | fallback`.

**`GET /api/spaceweather?days=30`**
```json
{ "fetchedAt": "2026-11-14T10:00:00Z", "live": true, "source": "NASA DONKI",
  "cmeCount": 4, "fastestCmeKmS": 1200, "maxKp": 6.0, "sepCount": 0,
  "recentNotifications": [ { "type": "RBE", "time": "2026-10-16T00:00Z" } ],
  "riskLevel": "medium" }
```
- Uses DONKI **CME, GST, SEP, notifications** through `api.nasa.gov`. The **FLR** endpoint currently returns 404 there (checked 2026-11-14) — don't depend on it.
- `riskLevel`: SEP in last 7 d or Kp ≥ 7 → `high`; CME ≥ 1000 km/s or Kp ≥ 5 → `medium`; else `low`.
- On failure, return `data/donki_snapshot.json` with `"live": false`; the game shows "data as of <date>". Never present static data as live.

**`POST /api/scores`**, **`GET /api/scores?scenario=mars&limit=10`**
```json
{ "nickname": "BraveFox42", "scenario": "mars", "solsSurvived": 14,
  "science": 13, "won": true, "durationSec": 410, "version": "0.3.0" }
```
Nicknames are **generated** (Adjective + Animal + number), no free text → no moderation, no personal data (audience 7–12).

**CORS:** `ALLOWED_ORIGINS` = `https://beibitai.github.io`, `https://*.itch.zone` (regex), `http://localhost:*`.

## 4. AI Commander

```
Unity (UnityWebRequest, 6 s timeout)
  └─► POST /api/commander
        ├─ rate limit: per IP + 1 call per sol per session
        ├─ cache key = (phase, event ids, outcome, value buckets) → reuse
        ├─ Gemini (GEMINI_API_KEY, GEMINI_MODEL=gemini-flash-lite-latest)
        └─ error/timeout → template from commander_fallback → 200 OK
Unity: no answer in 6 s → local template. Same UI either way.
```

- No key in the client or the repo; only `backend/.env` (gitignored) and Render env vars.
- System prompt: *friendly mission commander for kids 8–12; ≤ 40 words; simple English; use ONLY the numbers and facts provided; never scary; end with a tip.* JSON output (`text`, `tip`). Gemini rephrases the simulation — it cannot invent science numbers.
- SDK: `google-genai`. Model name from env so it can change without code changes.
- Gemini free tier may use prompts to improve Google products → we send only game state (no nickname, no personal data). Mention in the SI section.

## 5. 3D pipeline

| Rule | Value |
|---|---|
| Format | **FBX** into Unity; `.blend` stays in `art-source/` |
| Scale | 1 unit = 1 m; Blender Unit Scale 1.0; **Ctrl+A** apply all transforms |
| Pivot | bottom center of the module, at ground level |
| Export | Apply Scalings: FBX Units Scale; Forward −Z; Up Y; Unity import: **Bake Axis Conversion** |
| Reference sizes | astronaut 1.8 m; habitat Ø 5 m; base grid cell 8×8 m |
| Triangles | module 2–8k; astronaut ≤ 5k; terrain ≤ 30k; **whole scene ≤ ~150k** |
| Textures | ≤ 1024² (small props 512²), one material per module, BaseColor + Normal |
| Build size | target < 40 MB |

(Budgets are practical WebGL guidelines, not Unity limits — validate on the first build.)

**Naming:** `SM_` static mesh, `SK_` skinned, `T_<Asset>_<Map>.png`, `M_<Asset>.mat`. Path: `Assets/_Project/Art/Models/<Category>/`.

**Terrain:** Gale Crater DEM from [Mars Trek](https://trek.nasa.gov/mars/) → `data-pipeline` (rasterio) → 16-bit RAW heightmap 513×513 for Unity Terrain, or Blender (BlenderGIS) → mesh. Until then: flat plane with a rust material.

**Placeholders:** prefabs exist from the start with a cube as the `Model` child and final names; swapping the FBX replaces only that child.

## 6. WebGL build

- Publishing: **Compression = Gzip + Decompression Fallback = ON** (GitHub Pages does not send the needed Content-Encoding headers; the same build works on itch.io).
- Output to `web/play/`, commit only at milestones.
- Target: desktop Chrome/Edge. Landing shows "best on desktop" on mobile.
