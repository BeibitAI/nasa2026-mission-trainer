## Баланс P1 — сделано (Сб 14.11, ~22:30; 3000 случайных миссий, Python-порт `ResourceModel` + `EventDirector`)

Новые правила (физически честные, без выдуманных чисел):
- Фон на Марсе — в основном космические лучи: они есть всегда, щит их не останавливает. Частицы солнечной бури слабее — укрытие блокирует часть **добавки** от бури.
- Наука = работа снаружи: в бурю она опаснее (доза × сила бури).
- Буря без предупреждения застаёт экипаж снаружи → берём **реальный пиковый час** Curiosity (2.77×) вместо среднего за сутки (2.29×).
- Числа: `baseDosePerSol` 3.64, `outsideDosePerScienceUnit` 0.91, `doseLimit` 100, цель науки 32.

| Стратегия | До | После |
|---|---|---|
| Одно и то же каждый сол (лучший вариант) | 100% | **47%** |
| Реагировать на бури, со станцией | 92% | **92%** |
| Реагировать на бури, без станции | 94% | **27%** |
| Тяжёлый щит 3/2/4/1 | 0% | 0% |

R3 ✅ (нет бесплатного безопасного выбора), R6 ✅ (станция окупается), R8 🟡→✅ по механике. Нужна проверка руками в Unity (Арыстан, 5 партий).
